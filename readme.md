# Mermaid Preview

Mermaid Preview is an Acode plugin for Markdown files that makes technical docs easier to read on mobile and desktop.

## What you get

- Mermaid diagrams rendered directly from Markdown.
- Cleaner tables with stronger borders and spacing.
- Fenced code blocks styled like proper code snippets.
- Zoom controls for large diagrams so you can inspect details without squinting.

## How it feels

Open a `.md` file, press run/play, and the preview shows the document with diagrams, tables, and code formatted more clearly.

The plugin is meant for documents that mix explanatory text, API contracts, JSON examples, and Mermaid diagrams, so the preview stays readable instead of looking flat.

## Best for

- Solutioning docs
- API contract docs
- Technical notes with Mermaid diagrams
- Markdown files that contain long tables or JSON snippets
